# A Data-Driven Exploration of Airbnb Pricing and Popularity in New York City

What characteristics of 2019 NYC Airbnb listings are associated with differences in price and popularity?

**Team:** Anllela Sanchez, Lakshmi Prasanna Kalahastri, Bamina Fernando

## Dataset
- `data/AB_NYC_2019.csv` - raw data, 48,895 listings and 16 columns
- Source: Kaggle, [New York City Airbnb Open Data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)

## Project plan
1. Data cleaning and preprocessing
2. Exploratory data analysis (price, location, room type, reviews)
3. Regression models to predict price
4. Analysis of popularity (reviews) and subgroups (boroughs, neighborhoods)

## Tools
Python (Jupyter Notebook / Google Colab), pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Folium, GitHub

In progress. Scripts and notebooks will be added to this repository as the work is completed.
